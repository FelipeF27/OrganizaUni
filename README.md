# OrganizaUni

Aplicativo Android para organizar atividades acadêmicas por disciplina. Permite acompanhar trabalhos, provas, exercícios e leituras, com seus respectivos prazos e status de conclusão.

## Funcionalidades

- Cadastro e login com e-mail e senha.
- Cadastro de disciplinas e professores.
- Criação, edição e exclusão de atividades.
- Agenda com atividades agrupadas por data de entrega.
- Busca por atividade ou disciplina.
- Filtros de atividades pendentes e concluídas.
- Perfil do estudante com nome e curso.
- Armazenamento dos dados por usuário no Firebase.
- Modo de demonstração com dados de exemplo.

## Telas

Login, cadastro, Home, disciplinas, formulário de atividade, detalhes da atividade e perfil.
